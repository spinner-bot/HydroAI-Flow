**AI-assisted Hydrodynamic Modeling &amp; Simulation**

用 AI 代理模型加速水动力数值模拟的重复计算与参数率定。

> **当前阶段：需求收集与方案定义。**
> 仓库内暂无代码实现。研究对象、预测变量、数据条件等关键前提仍在组会中确认，尚未定稿。

---

## 项目背景

水动力数值模拟（如 Delft3D）能给出物理上可信的水位、流场与输运结果，但单次计算成本高。当需要反复调整参数、反复对比方案时，计算时间会成为迭代速度的主要瓶颈。

本项目探索的方向是：**用 AI 代理模型承担其中一部分数值计算**，在精度基本不下降的前提下，缩短「改参数 → 看结果」的反馈周期。

上述方向来自组会讨论（见 [`meeting/`](meeting/)）。它目前是方向而非结论——**下列问题尚未确定**：

- 具体研究的对象是什么（河流 / 湖泊 / 水库 / 近岸海域 / 海湾）
- 最终要预测什么（水位 / 流速 / 波浪 / 泥沙 / 污染物扩散）
- 「预测未来 24 小时」是否成立，还是仅为举例
- AI 的输入输出是什么，可接受的误差范围是多少
- 现有数据是否足以支撑模拟、训练与验证

这些问题正在 [`meeting/9221-收集预备/`](meeting/9221-收集预备/) 中逐条收集。

---

## 三条主线

| 主线 | 要解决的问题 |
| --- | --- |
| **数值模拟** | 明确 Delft3D 的算例、可调参数、输出变量，以及「计算慢」具体慢在哪一环 |
| **代理模型** | 定义 AI 替代哪部分计算、输入输出是什么、与数值模拟的精度差距可接受到什么程度 |
| **参数率定** | 把人工调参的依据与历史数据，转化为可自动优化的目标 |
