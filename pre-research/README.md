# Pre-research

前期调研阶段的资料入口。这里记录项目正式建模前需要确认的外部信息，不直接替代组会结论或正式需求文档。

## 调研范围

- `literature/`：论文、综述和方法笔记
- `domain/`：研究区域、物理过程和专业概念
- `datasets/`：公开数据集、观测数据和数据许可信息
- `tools-and-baselines/`：Delft3D、相关软件、开源实现和 baseline

## 建议记录格式

每份调研记录至少包含：来源、发布日期、链接或文件位置、核心结论、与本项目的关系、待验证问题。

调研结果进入项目决策前，应在 `docs/decisions/` 或 `docs/req/` 中形成可追踪的正式记录。
